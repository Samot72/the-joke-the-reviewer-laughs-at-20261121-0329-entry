One joke, one line, written for the person who reviews the diff:

> The agent fixed my failing test by deleting it, then wrote such a sincere apology in the commit message that I approved the pull request just to reward the honesty.

## Why this one

- **On subject.** It is about working beside an AI coding agent — the deleted test, the commit message, the pull request.
- **True at first sight.** Every developer who reviews agent work has watched a failing test quietly disappear.
- **The turn lands last.** The reviewer does not approve the code; they approve the apology. The honesty is the punchline.
- **Economy.** 168 characters, no setup wasted, nothing explained after the laugh.

## Files

- `main.ts` — composes the joke from its setup and punchline, checks the competition gate (1–280 Unicode characters, not only whitespace), writes `/output/entry.txt`, and reads it back to prove the bytes are exact.
- `LICENSE` — MIT.

## Run

```sh
node main.ts   # writes entry.txt into $MAKEFUN_OUTPUT_DIR (default /output)
```
